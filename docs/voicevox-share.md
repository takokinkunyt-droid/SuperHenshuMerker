# 自分の VOICEVOX を友達と共有する

スーパー編集メーカーの「🗣 読み上げ」は、パソコンで動いている VOICEVOX を使って音声を作ります。
`tools/voicevox-share.mjs`（共有サーバー）を使うと、**あなたのパソコンの VOICEVOX を、友達がスマホやパソコンから使える**ようになります。

```
友達のスマホ ──https──▶ Cloudflare のトンネル ──▶ 共有サーバー（合言葉を確認）──▶ あなたの VOICEVOX
```

- 合言葉を知っている人だけが使えます（合言葉は共有リンクに入っています）。
- 読み上げに必要な機能（声の一覧・読み上げ）だけを通し、VOICEVOX の設定変更や辞書の書き換えなどは通しません。
- 1回に読み上げられるのは500文字まで、同時に処理するのは2件までにして、パソコンが重くなりすぎないようにしています。

## 最初に1回だけ準備すること（Windows）

1. **Node.js** を入れる（すでに入っていれば不要）：https://nodejs.org の LTS 版
2. **cloudflared**（Cloudflare のトンネル）を入れる：PowerShell で次を実行
   ```powershell
   winget install --id Cloudflare.cloudflared
   ```
3. このリポジトリの `tools` フォルダを用意する（`git clone` 済みなら `git pull` で最新にする）

## 共有するとき（毎回）

1. **VOICEVOX を起動**する
2. `tools` フォルダの **`voicevox-share.bat` をダブルクリック**する
   （Mac・Linux はターミナルで `node tools/voicevox-share.mjs`）
3. 10秒ほどで「**友達に送る共有リンク**」が表示されるので、コピーして LINE などで友達に送る
4. 友達がそのリンクを開くと、読み上げの設定が自動で済み、「🗣 読み上げ」からあなたの VOICEVOX の声が使えます

共有をやめるときは、黒いウィンドウを閉じます（または Ctrl+C）。

## 知っておくこと

- **共有中はパソコンと VOICEVOX を起動したままにしてください。** 閉じると友達は読み上げを使えなくなります。
- 無料のトンネルを使っているので、**起動するたびに共有リンクの URL が変わります。** 起動し直したら新しいリンクを送ってください。
- 合言葉は `tools/voicevox-share.json` に保存され、次回も同じものを使います。リンクが知らない人に広まったときは
  `node tools/voicevox-share.mjs --new-key` で合言葉を作り直してください（前のリンクは使えなくなります）。
- 自分のパソコンだけで試すときは `--no-tunnel` を付けると、トンネルを開かずに起動します。
- VOICEVOX の声を使った動画には「VOICEVOX:キャラ名」のクレジット表記が必要です（書き出し画面に表示されます）。
  VOICEVOX と各キャラクターの利用規約（https://voicevox.hiroshiba.jp/term/ と各キャラクターのページ）も、共有する人・使う人それぞれで確認してください。
